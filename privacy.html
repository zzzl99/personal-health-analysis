主页隐私政策使用条款

隐私政策

更新时间：2026-10-25。本政策适用于 Personal Health Analysis Local 本机只读接入工具。

访问的数据

经用户明确授权，工具读取 Google Health 的睡眠、活动与健身、健康指标与测量数据，以及用于查询设备型号、电量和最后同步时间的设置数据。工具不申请云端写入、删除或 GPS 位置权限。

用途与保存

数据用于个人趋势分析和数据同步状态检查。OAuth 令牌、配置和健康记录保存在用户电脑的私有目录中，文件访问权限限制为当前系统用户。文件并非由本工具加密，电脑及磁盘加密由用户操作系统管理。

共享

授权及同步请求发送给 Google 官方服务。本静态说明网站不接收健康数据。用户请求 Codex 分析时，选取的数据会发送到该 Codex 会话所使用的服务，处理方式受该服务条款、隐私政策及用户账号设置约束。工具本身不出售健康数据，不用于广告，也不训练模型。

保留与删除

本机快照和同步观察记录会保留到用户删除为止。用户可以停止同步程序、在 Google 账号的第三方连接管理中撤销本工具授权，并删除本机私有目录。撤销授权不会自动删除既有本机文件或已经发送到 Codex 的会话内容；后者须在相应服务中单独管理。

控制与联系

用户可拒绝任一权限或随时撤销授权。缺少必要权限时相关读取功能无法使用。如需联系维护者，请使用 Google OAuth 同意页显示的支持邮箱。

Google 数据使用

通过 Google API 收到的信息仅用于以上用户请求的功能，并遵守 Google API Services User Data Policy，包括适用的 Limited Use 要求。
